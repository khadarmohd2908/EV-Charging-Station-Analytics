# EV-Charging-Station-Analytics
End-to-end EV charging analytics project using Excel, SQL, Python and Power BI
# EV Charging Station Analytics & Performance Dashboard
 Project Overview
This project analyzes EV charging station data to understand revenue,
charging demand, station performance, customer behavior, and operational
efficiency.
## Tools Used
- Excel
- MySQL
- Python
- Power BI
- Power Query
- DAX
## Project Workflow
Excel Data Cleaning
→ SQL Analysis
→ Python EDA
→ Power BI Dashboard
→ Business Insights

## Key Analysis

- Revenue analysis
- Charging session analysis
- Top performing stations
- EV model usage
- Charger type performance
- Customer analysis
- Peak charging hours
- Station failure rate
- Monthly revenue trends

## Power BI Dashboard

The dashboard contains:

### Page 1 - Executive Overview
- Total Revenue
- Total Sessions
- Total Energy
- Average Charging Duration
- Average Revenue per Session
- Failure Rate

### Page 2 - Station Performance
- Top 10 Stations
- Station Revenue
- Sessions per Charger
- Failure Rate by Station

### Page 3 - Customer & EV Analysis
- Customer Type
- Membership
- EV Model Usage
- Revenue by Customer Type

### Page 4 - Operations Analysis
- Peak Charging Hours
- Payment Methods
- Charger Type
- Completed vs Failed Sessions

## SQL Analysis

SQL was used for:

- Data validation
- Revenue analysis
- Station ranking
- Customer analysis
- Monthly revenue
- Peak-hour analysis
- Failure-rate analysis
- Window functions and CTEs

## Python EDA

Python libraries used:

- Pandas
- NumPy
- Matplotlib
- Seaborn

EDA included data cleaning, statistical analysis,
trend analysis, and visualization.

## Business Insights
The project identifies high-performing stations,
peak charging periods, popular EV models, charger utilization,
and operational issues to support data-driven decisions.
